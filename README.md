# Análise de Incêndios Florestais no Brasil

Projeto de análise exploratória de dados sobre registros de incêndios florestais no Brasil entre 1997 e 2017.

## Objetivo

Analisar a série histórica de incêndios para identificar padrões temporais, sazonalidade, estados com maior ocorrência e a distribuição geográfica dos registros.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly
- Google Colab

## Análises realizadas

- Estrutura e qualidade dos dados
- Valores nulos e estatísticas descritivas
- Evolução anual dos incêndios
- Distribuição dos incêndios por mês
- Ranking de incêndios por estado
- Evolução anual dos 10 estados com maior ocorrência
- Visualização geográfica interativa

## Base de dados

A base utilizada no projeto está disponível no Google Drive.

## Como executar

1. Abra o arquivo `Projeto_Incendios_Florestais.ipynb` no Google Colab ou Jupyter Notebook.
2. Instale as dependências listadas em `requirements.txt`, caso necessário.
3. Execute as células em ordem.

O notebook faz a leitura da base diretamente do Google Drive.
